# Jisoo Kim

English academic homepage for Jisoo Kim, a master's student in the Department of AI Convergence Security at Soongsil University.

**Research interests:** Large Language Models, AI Security, AI Safety.

## Structure

- `index.html`: profile, research interests, education, and contact information.
- `styles.css`: responsive styling.
- `script.js`: email copy and section navigation.
- `assets/`: portrait and favicon.

The site is static and does not require a build step. A generic Selected work template is retained in an HTML comment for future public work.

## GitHub Pages

Publish the `main` branch from the repository root using **Settings → Pages → Deploy from a branch**. All asset paths are relative.

## Updates

Edit the text in `index.html` and replace assets as needed. The portrait is provided by the site owner; no blanket license is applied to personal materials.
